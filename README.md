# Data Structures Practical Questions

## Array Operations

1. Write a C program to traverse and display the elements of an array.
2. Write a C program to insert an element into an array at a given position.
3. Write a C program to delete an element from an array at a given position.
4. Write a C program to perform binary search on an array in ascending and descending order.

## Stack and Queue

5. Write a C program to implement a stack using an array.
6. Write a C program to implement a queue using an array.
7. Write a C program to implement a circular queue using an array.
8. Write a C program to convert an infix expression into a postfix expression.
9. Write a C program to convert an infix expression into a prefix expression.
10. Write a C program to evaluate a postfix expression.
11. Write a C program to solve the Tower of Hanoi problem using recursion.

## Singly Linked List

12. Write a C program to create a singly linked list.
13. Write a C program to display the elements of a singly linked list.
14. Write a C program to count the number of nodes in a singly linked list.
15. Write a C program to insert a node into a singly linked list at the beginning, end, and a given position.
16. Write a C program to delete a node from a singly linked list at the beginning, end, and a given position.
17. Write a C program to search for an element in a singly linked list.
18. Write a C program to reverse a singly linked list.
19. Write a C program to sort a singly linked list.
20. Write a C program to remove duplicate elements from a singly linked list.
21. Write a C program to concatenate two singly linked lists.

## Doubly and Circular Linked Lists

22. Write a C program to create and display a doubly linked list.
23. Write a menu-driven C program to perform insertion and deletion at the beginning, end, and a given position in a doubly linked list, and to display the list.
24. Write a C program to print the elements of a singly linked list in reverse order using recursion.
25. Write a C program to create and display a singly circular linked list.
26. Write a C program to perform insertion and deletion at the beginning, end, and a given position in a singly circular linked list.
27. Write a C program to implement a stack using a singly linked list.
28. Write a C program to implement a queue using a singly linked list.
29. Write a C program to implement a deque using a doubly linked list.
30. Write a C program to represent and add two polynomials using linked lists.
31. Write a C program to multiply two polynomials using linked lists.
32. Write a C program to represent a sparse matrix using a linked list.
33. Write a C program to create and display a circular doubly linked list in forward and backward directions.

## Sorting Algorithms

34. Write a C program to implement bubble sort.
35. Write a C program to implement insertion sort.
36. Write a C program to implement selection sort.
37. Write a C program to implement quick sort.
38. Write a C program to implement merge sort.
39. Write a C program to solve the Tower of Hanoi problem non-recursively using stacks.

## Graph Algorithms

40. Write a C program to implement breadth-first search (BFS) recursively using an adjacency matrix.
41. Write a C program to implement depth-first search (DFS) recursively using an adjacency matrix and a visited array.

## Binary Tree

42. Write a C program to create a dynamic binary tree using structures and pointers, and display it using non-recursive inorder traversal.
43. Write a C program to count the total number of nodes in a binary tree using recursion.
44. Write a C program to count the leaf nodes in a binary tree using recursion.
45. Write a C program to perform preorder, inorder, and postorder traversals of a binary tree non-recursively using stacks.

## Binary Search Tree (BST)

46. Write a C program to insert elements into a binary search tree (BST) and display the tree using inorder traversal.
47. Write a C program to delete a node from a binary search tree.
48. Write a C program to search for an element in a binary search tree.

## AVL Tree

49. Write a C program to implement AVL tree insertion with height calculation, balance factor calculation, and LL, RR, LR, and RL rotations.
50. Write a C program to search for an element in an AVL tree.
51. Write a C program to delete a node from an AVL tree and rebalance the tree.

## Heap

52. Write a C program to implement a max-heap with insertion, deletion of the root element, and display operations.
53. Write a C program to implement a min-heap with insertion, deletion of the minimum element, and display operations.
54. Write a C program to implement a max-heap using an array and insertion.
55. Write a C program to implement heap sort using a max-heap.
56. Write a C program to implement a priority queue using a max-heap.

## Hashing

57. Write a C program to implement a hash table using linear probing with insertion, searching, deletion, and display operations.
58. Write a C program to implement a hash table using quadratic probing with insertion, searching, deletion, and display operations.
59. Write a C program to implement a hash table using separate chaining with linked lists.
60. Write a C program to implement a hash table using double hashing.
61. Write a C program to store and search student records using a hash table with linear probing.
62. Write a C program to implement an employee database using a hash table with quadratic probing.
63. Write a C program to implement a simple dictionary using hashing and linear probing.
64. Write a C program to count the frequency of numbers in an array using hashing and linear probing.

## Binary Tree Applications

65. Write a C program to find the mirror image of a binary tree.
66. Write a C program to create a double tree by inserting a duplicate node as the left child of every node in a binary tree.
67. Write a C program to perform non-recursive inorder, preorder, and postorder traversals of a binary tree using stacks.
